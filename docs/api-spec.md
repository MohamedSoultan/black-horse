# API additions: Provider ecosystem

Provider endpoints are documented in the approved contract and implemented under `/api/v1`: public categories/directory/details, authenticated application/profile operations, and admin review actions.

Services add public category/list/detail endpoints plus Admin/Super Admin CRUD under `/api/v1/admin/services`.

Portfolio adds public category/list/detail endpoints plus Admin/Super Admin CRUD under `/api/v1/admin/portfolio`.

Requests add public submission, private user listing/detail, and admin listing/status/assignment endpoints under `/api/v1`.

Notifications add authenticated listing, unread count, and mark-as-read endpoints under `/api/v1/notifications`.
